# Project Overview

## AI-Driven Gamification for Personalized Wellbeing Monitoring in Mental Health Applications

This Final Year Project focuses on using AI-supported gamification to encourage continued engagement with digital mental wellbeing activities.

The work forms one module within a larger collaborative university mental-health application. My FYP contribution focuses on the gamification and personalised wellbeing-monitoring concept, including mood-based interaction, wellness activities, rewards, progress tracking and AI-assisted personalised feedback.

## Main FYP Focus

- Mood-based user interaction
- Gamified wellbeing activities
- Rewards and progress tracking
- AI-assisted personalised feedback
- User engagement and behavioural interaction
- Integration with the wider university mental-health application

## Application Context

The wider application was developed collaboratively by a group of student developers, with different students responsible for different features/modules. This repository preserves the integrated project source used in the development environment while the README clearly identifies the FYP focus described above.

## Technology

- Flutter / Dart
- Python / FastAPI
- PostgreSQL
- REST APIs
- AI/ML service integration
